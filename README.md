\## 2. Visão Geral



O projeto consiste no desenvolvimento de uma calculadora em Java, com operações matemáticas básicas. O objetivo é aplicar os conceitos de programação, testes de software, refatoração e documentação do código.



\## 3. Problema



Uma calculadora precisa executar operações matemáticas corretamente e apresentar um código organizado, fácil de entender e manter. Para isso, é importante verificar seu funcionamento por meio de testes e melhorar a estrutura do código por meio da refatoração.



\## 4. Objetivo



Desenvolver e validar uma calculadora em Java, aplicando testes automatizados, refatoração e geração de documentação com JavaDoc.



\## 5. Escopo Funcional



O projeto contempla as seguintes funcionalidades:



\- Realizar operações matemáticas básicas.

\- Organizar as operações em métodos.

\- Verificar o comportamento das operações por meio de testes automatizados.

\- Melhorar a organização e a legibilidade do código.

\- Gerar documentação técnica utilizando JavaDoc.



\## 6. Requisitos Não Funcionais



\- \*\*Organização:\*\* o código deve ser estruturado e legível.

\- \*\*Manutenibilidade:\*\* os métodos devem ser claros e fáceis de modificar.

\- \*\*Confiabilidade:\*\* as operações devem apresentar resultados corretos.

\- \*\*Testabilidade:\*\* o projeto deve permitir a execução de testes automatizados.

\- \*\*Documentação:\*\* o código deve possuir comentários e documentação técnica.
